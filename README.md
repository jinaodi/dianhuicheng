# 讲解成片

> 把一份稿子，变成带配音、带字幕、带版式的 1080P 讲解视频。
> **纯本地运行，不需要联网、不需要登录、不需要安装任何软件。**

---

## 30 秒上手

1. 双击 `讲解成片_v1.0.html`（用 Chrome / Edge 打开），页面会自带一份产品发布示例。
2. 点顶栏「① 稿子」，把示例文字换成你自己的讲稿，点「自动分镜」。
3. 点「② 风格」挑配色、音色、语速；右侧缩略图可点着切版式。
4. 点「③ 点播」听一遍，字幕与画面会跟着走。
5. 点「④ 导出成片」→ 选「浏览器导出」，得到音频 + 字幕 + 每页画面。

> 想要一个完整的 MP4：见下方「导出一整个 MP4」。

## 这是给谁用的

| 谁 | 什么时候用 | 得到什么 |
| --- | --- | --- |
| 学生 / 研究生 | 课程汇报、组会、开题预演 | 一份能自己念的讲稿视频，先对着看，再上台 |
| 老师 | 微课、知识点讲解 | 无需录屏、无需剪映的短片，字幕自动对齐 |
| 职场人 | 周报 / 复盘 / 项目介绍 | 不露脸的讲解视频，避免对着屏幕录到一半卡壳 |
| 自媒体 | 口播稿试片、图文转视频 | 把图文稿快速变成"有意义"的画面，不用逐帧配字幕 |

它**不能**做的：不是 AI 生成文案，不是 AI 配音"拟真大模型人声"，不做真人影像替换。

## 稿子怎么写（决定成片好看的程度）

分镜是规则化的：从你的文字里读结构，所以写得越"有结构"，成片越好看。

```markdown
## 一、先说痛点
每次汇报前都要花两小时排版。

## 二、再说解法
只需要写稿子，剩下的交给工具。

## 三、最后收尾
把时间还给内容本身。
```

- `## 小标题` → 会作为一个分页块被保留。
- 一段里出现 2 条以上的短句列表（以 `-` `·` `1.` 开头）→ 自动变成「要点列表」版式。
- 一段里出现 2 个以上"数字+单位"（`38%`、`12.4万`、`3分钟`）→ 自动变成「数字卡片」版式。
- 一句话里只有一个数字且总字数不多 → 自动变成「图文分栏」。
- 最后一页出现"总结 / 结论 / 应该" → 自动变成「金句页」。
- 其余 → 「标题页」。
- 想要强调：用 `[方括号]` 包住，合成时会重读，画面会高亮（字幕里会自动去掉方括号）。

挑完分镜后，每一页都能在「① 稿子」里单独改标题、正文、版式、要点、数字、金句。

## 导出一整个 MP4

浏览器出于安全限制，不能直接把画面和声音封装成 MP4，所以提供两条路：

### 方案 A：一条命令（需要 Node.js，已装好依赖）

```bash
node tools/make-video.js pitch shots/video/pitch.mp4
```

`pitch` 是示例名（`pitch` / `report` / `course`）。脚本会逐帧渲染 1920×1080、合成离线配音、调用 FFmpeg 输出 H.264 + AAC 的 MP4。约 1 分钟的视频耗时 1~2 分钟。

### 方案 B：导出素材包 + 任意视频软件

在「④ 导出成片」点「浏览器导出」，会下载：

- `配音.wav` —— 完整离线配音
- `字幕.srt` —— 与配音逐句对齐的字幕，可直接拖进剪映 / Premiere
- `口播脚本.txt` —— 带时间码的稿子
- `01_xxx.png` ~ `NN_xxx.png` —— 每页 1920×1080 的画面

把这四样拖进剪映，只做一件事：把每张图的时长拖到与字幕对齐（或直接丢掉图片，用剪映自动分镜）。**不需要自己配字幕。**

## 项目文件（`.jpc`）

顶栏「保存」会存成一个 `.jpc` 文件（就是 JSON），可以反复修改、发给别人。它包含：

```
project
├── title / author      # 标题与作者
├── preset              # 配色主题
├── voice               # 音色、语速、音调
├── style               # 背景、动画、字幕开关
└── slides[]            # 每一页
    ├── layout          # cover / title / bullets / split / numbers / quote / timeline / compare
    ├── kicker / title  # 小标签与标题
    ├── body            # 正文（用 [方括号] 标重音）
    ├── bullets[]       # 要点列表
    ├── stats[]         # 数字卡 {value, label}
    └── quote / source  # 金句与出处
```

所有字段都是纯文本，适合版本管理；你也可以用别的程序生成 `.jpc` 再丢进来。

## 已知边界（如实说明）

1. **合成人声是"参数化合成"，不是真人录音**。它能把字读清楚、声调基本正确，但没有大模型 TTS 的自然度。工程上它换来的是：零依赖、离线、每句时长完全可控（这正是字幕与画面能自动对齐的前提）。
2. **分镜是规则化的，不是语义理解**。它能识别结构（小标题、列表、数字、总结），但不能判断你的观点哪句最重要。想更准，就手动改版式。
3. **浏览器版不直接出 MP4**，因为浏览器不能封装视频容器；见上方两条导出路径。
4. 只内置了简体中文与常用英文数字；生僻字会按部件兜底发音，可能不准。

## 目录结构

```
讲解成片/
├── 讲解成片_v1.0.html       ← 作品本体，双击即用
├── 示例成片_产品发布.mp4     ← 用本工具生成的一段成片
├── src/
│   ├── engine/             ← 引擎（可脱离界面单独调用）
│   │   ├── packet.js       ← .jpc 数据结构
│   │   ├── timeline.js     ← 断句、估时长、对齐
│   │   ├── voice.js        ← 离线合成（共振峰 + 声调）
│   │   ├── pinyin-data.js  ← 2.1 万字拼音字典
│   │   ├── backgrounds.js  ← 8 种版式与动画
│   │   └── templates.js    ← 稿子 → 分镜
│   └── app/                ← 四步界面
├── tools/
│   ├── make-video.js       ← 一条命令出 MP4
│   ├── build-single.js     ← 打包成单文件 HTML
│   ├── e2e.js              ← 自动化验收
│   └── audio-probe.js      ← 合成音体检
└── dist/讲解成片.html       ← 打包产物
```

引擎（`src/engine/*.js`）不依赖 DOM，可以直接在 Node 里 `require` 使用，把自己的稿子批量生成画面与音频。
